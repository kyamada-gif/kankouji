# 2級管工事 第一次検定 過去問の重複・類似分析（平成28年度後期〜令和8年度前期、18回・936問）

作成日: 2026-10-15　　可視化: `dashboard/index.html`（公開版は Artifact）

## 1. 結論

- **選択肢まで一致する「同一」問題は 171問（127ペア）**。936問の 18% が別の回にそっくり再出題されている。
- 選択肢1つの差替えや軽微な修正（ほぼ同一）まで含めると、**110の問題ファミリー・251問（27%）**。
- 選択肢の一部を再利用した「類似」まで広げると、**直近4回（令和6年度後期〜令和8年度前期）の問題の 72.6% が過去回のどれかと重なる**。うちほぼそのままが 19.2%。
- 選択肢（文）単位では、全3523肢のうち **1587肢（45%）が別の回にも登場**。各回の「過去回に同じ肢があった割合」は平成30年度の14%から令和4年度後期以降は33〜40%へ上昇。
- 論点は84クラスタに分かれ、保温・塗装、品質検査（抜取・全数）、労働安全衛生法、屋内消火栓、工程表、建設業法の標識、建築基準法の用語、給水設備などは18回中ほぼ毎回出題。
- 正答番号の分布は 1〜4 がほぼ均等（{'1': 243, '2': 243, '3': 248, '4': 246}）で、番号の偏りは利用できない。

## 1-3. 類似問題は同じ論点を問うているか

選択肢を一致率0.8以上で対応付け、両問の正答肢（＝問われている誤りの記述）が共有されているかを見た。

| 関係 | ペア数 | 正答肢を共有（同じ論点を問う） | 正答肢が入れ替わる | 共有は誤答肢のみ |
|---|---|---|---|---|
| 同一 | 127 | 88（69%） | 29（23%） | 10（8%） |
| ほぼ同一 | 55 | 41（75%） | 8（15%） | 6（11%） |
| 類似 | 677 | 159（23%） | 127（19%） | 391（58%） |

同一・ほぼ同一では7割前後が同じ誤り記述を正答として問い直している。類似では、共有される選択肢の多くは誤答側の「正しい記述」で、問われる論点そのものは別の肢に移っていることが多い。ただし類似ペアの約6割は問題文の主題（給水設備、工程表など）が同じで、同じテーマの中で「どの記述を誤りに作り替えるか」を入れ替えている構図である。

## 2. 手法（調査結果にもとづく選定）

重複検出の標準的な構成は「厳密一致 → 字面の近似重複（MinHash/LSH）→ 意味的重複（埋め込み）」の多段パイプライン（NVIDIA NeMo Curator などの整理）で、日本語は分かち書きがないため文字 n-gram を使う。意味側は JMTEB ベンチマーク上位の日本語埋め込み（Ruri v3、PLaMo-Embedding）が最有力だが、本環境からは配布元に到達できなかったため GiNZA（ja_ginza）の単語ベクトルと TF-IDF で代替した。論点抽出は BERTopic 流の UMAP → HDBSCAN → c-TF-IDF。

1. 正規化: NFKC、空白除去、2解答問題の定型文「〜二つとも答えなさい」を除去。
2. 字面: 文字3-gram の MinHash LSH（閾値0.25/0.4）で候補を出し、Jaccard と difflib 一致率を厳密計算。選択肢は最良マッチの一致率 0.9 以上を「同じ肢」、0.8 以上を「軽微な修正」とみなす。
3. 意味: GiNZA の名詞・動詞・形容詞・数詞の TF-IDF コサイン、単語ベクトル平均のコサイン。
4. 分類（別の回どうしのペアのみ）:
   - 同一: 全文一致率 ≥ 0.92、または 4肢すべて一致
   - ほぼ同一: 3肢一致、または 4肢が軽微修正で一致
   - 類似: 2肢以上が軽微修正で一致、または 1肢一致かつ問題文の主題が同じ（主題一致率 ≥ 0.6 か TF-IDF ≥ 0.4）
   - 同一論点: 問題文の主題一致率 ≥ 0.85 または TF-IDF ≥ 0.55（肢は別）
5. 論点クラスタ: TF-IDF → SVD 60次元 ＋ 単語ベクトル → UMAP（5次元、cosine）→ HDBSCAN（min_cluster_size 6）。ラベルは c-TF-IDF 上位語。
6. 問題ファミリー: 同一・ほぼ同一のペアで連結した成分。

抽出品質: HTML と PDF の両方がある14回で問題文＋選択肢の一致率は平均 0.97、中央値 1.00。

## 6. アプリ設計への示唆

- 「ファミリー」単位で問題を束ね、同一問題を重複して出題しない／既習扱いにする。
- 選択肢文を「命題」として独立管理し、○×の暗記カード化する（45%の肢が再利用される）。
- 毎回出る論点クラスタ（保温・塗装、品質検査、安衛法、消火栓、工程表、建設業法、建築基準法用語、給水）を優先出題する。
- 旧形式（〜令和2年度）の施工管理法14問は現行の10問＋能力問題4問に再マッピングして扱う。
