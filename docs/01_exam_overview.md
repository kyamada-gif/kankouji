# 2級管工事施工管理技術検定 第一次検定 ― 試験概要と過去問の収集状況

作成日: 2026-10-15

## 1. 試験の基本情報

| 項目 | 内容 |
|---|---|
| 実施機関 | 一般財団法人 全国建設研修センター（JCTC） https://www.jctc.jp/ |
| 実施回数 | 年2回（前期: 6月上旬、後期: 11月中旬）。前期は第一次検定のみ。後期は第一次・第二次 |
| 年2回化の開始 | 平成30年度（2018年度）から（平成29年度以前は年1回・11月のみ） |
| 出題形式 | 四肢択一（マークシート） |
| 出題数 / 解答数 | 52問出題 / 40問解答（必須15問 + 選択25問） |
| 合格基準 | 40問中24問以上（正答率60%以上） |
| 注意点 | 選択問題は必要解答数を超えて解答すると減点 |
| 制度改正 | 令和3年度（2021年度）: 「学科試験」→「第一次検定」。施工管理法（基礎的な能力）4問が追加され、合格者に「2級管工事施工管理技士補」の称号 |
| 受検資格 | 令和6年度（2024年度）から第一次検定は17歳以上（受検年度末時点）なら誰でも受検可能 |
| 問題公開 | 試験日の翌日13時にJCTCサイトで問題PDFと正答肢PDFを公開（解説はなし） |
